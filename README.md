# Static portfolio site

Zero-dependency HTML/CSS portfolio for GitHub Pages. It is intentionally based only on public, documented facts from the selected repositories.

## Publish bridge action (when requested)

1. Create a repository named `portfolio` under `Pruthviii23`.
2. Upload `index.html` and `styles.css` from this folder to the repository root.
3. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. Wait for the Pages URL and send it to Aster for verification.

No build command, paid service, or API key is required.
